# SSL Certificates for Local Development

This directory contains SSL certificates for the local development environment.

## Generating Certificates

To generate self-signed SSL certificates for `local-www.rogerssportsandmedia.com`, run:

```bash
chmod +x generate-cert.sh
./generate-cert.sh
```

The script will generate:
- `local-www.rogerssportsandmedia.com.crt` - Certificate file
- `local-www.rogerssportsandmedia.com.key` - Private key file

## Trusting the Certificate (macOS)

To avoid browser warnings about the self-signed certificate on macOS:

```bash
sudo security add-trusted-cert -d -r trustRoot -k /Library/Keychains/System.keychain local-www.rogerssportsandmedia.com.crt
```

## Trusting the Certificate (Linux)

For Ubuntu/Debian:

```bash
sudo cp local-www.rogerssportsandmedia.com.crt /usr/local/share/ca-certificates/
sudo update-ca-certificates
```

## Browser Configuration

In your browser, if you still see certificate warnings:

1. Click "Advanced" or "More information"
2. Click "Proceed to site" or "Continue anyway"
3. Optionally, add the certificate to your browser's trusted store

## Certificate Expiration

Self-signed certificates generated by the script are valid for 365 days. To regenerate them, run the `generate-cert.sh` script again.

## Security Note

⚠️ These are self-signed certificates for **LOCAL DEVELOPMENT ONLY**.
Do not use these in production environments.
